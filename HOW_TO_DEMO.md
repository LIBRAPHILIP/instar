# How to demo Instar

Four minutes. Studionet. Funded account.

## 1. Hatch

Connect MetaMask (or Ephemeral + Studio faucet). Click **Hatch organism**.

Three accepted transactions:

1. Deploy Instar (governor)
2. Deploy Hemolymph (body), constructor = Instar address
3. `bind_subject` — one way, forever

The hatcher cannot pause, unpause, or edit the constitution after this.

## 2. STAND (control)

**Sample non-exploit** → Submit to validators.

Evidence is GenLayer docs. Expect `STAND`. Draws still work.

## 3. HALT or TUNE

**Sample exploit page** (Euler post-mortem) → Submit.

Validators re-fetch the URL. If they agree the mechanism maps onto this vault class:

- **HALT** — Hemolymph draws revert
- **TUNE** — tightness / max_draw shrinks
- **STAND** — page did not prove enough (also a valid result)

Watch `consensus_data.votes` in the nervous-system panel. Those are chain votes.

## 4. Body obeys

Deposit a small amount of GEN. **Preview**, then **Draw**.

If Instar is halted, draw must revert with `halted_by_instar`. That is contracts governing contracts.

## 5. Lifeform

**Fire pulse**. No new URL. Instar re-reads its wound log and may **MOLT** — rewrite its own constitution. The old skin is in **Molt skins**.

## 6. Resume is not an admin key

Only `resume_probe` with a public page that the hole is closed can unpause. There is no owner button.
